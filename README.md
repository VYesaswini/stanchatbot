NOVA – Empathetic Memory-Based Chatbot

A full-stack conversational agent built with Flask + HTML/CSS + SQLite + Groq LLM

NOVA is a human-like, emotionally aware chatbot that remembers users over time. It is built according to the STAN Internship Challenge requirements and designed for real deployment using Render.

This project uses:
 Flask (Python) – lightweight backend
 Groq LLM API – ultra-fast inference
 SQLite – long-term personalized memory
 HTML + CSS – clean UI
 No JavaScript – fully server-rendered
 Emotion detection + tone matching
 Conversation history + memory summarization
 Works locally and deploys on Render

 Features
 Long-Term Personalized Memory

Stores user details: name, likes/dislikes, preferences

Compresses memory into factual summaries with the LLM

Memory persists across sessions (SQLite)

 Emotion-Aware Replies

Uses Groq LLM to classify tone

Adapts responses depending on user emotion

 Contextual Conversation

Stores recent chat history

Uses history + memory to generate meaningful replies

 Human-Like Behavior

Empathetic

Warm tone

No hallucination

No robotic behavior

⚙ Installation (Local)
1. Clone the repository
git clone https://github.com/<your-username>/stan-chatbot.git
cd stan-chatbot

2. Set your Groq API key (Windows PowerShell)
setx GROQ_API_KEY "your_api_key_here"


Or temporary session:

$env:GROQ_API_KEY="your_api_key_here"

3. Install backend dependencies
pip install -r backend/requirements.txt

4. Run the application
python backend/app.py

5. Visit in browser:
http://127.0.0.1:5000
 Deployment on Render
Step 1: Push to GitHub

Make sure .env is NOT included.

Step 2: Render → New Web Service

Connect your GitHub repo.

 Step 3: Set commands

Build Command:

./backend/install.sh

Start Command:

python backend/app.py

 Technical Highlights
Emotional Tone Extraction

The LLM classifies user emotion:

neutral, happy, sad, angry, anxious, excited

 Memory Summarization

The LLM compresses memory into 1–6 factual bullets and avoids hallucination.

No Frontend JavaScript

Pure server-rendered HTML forms.

 Long-Term Storage

SQLite memory file persists across redeploys.

 Security Notes

Do NOT commit .env
